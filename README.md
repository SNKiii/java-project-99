# Task Manager (Java)

Task Manager — это веб-приложение для управления задачами.

 Функции

- Регистрация и аутентификация пользователей
- Управление задачами (CRUD)
- Управление статусами задач
- Управление метками
- Фильтрация задач по названию, исполнителю, статусу и меткам
- JWT авторизация

 Технологии

- Java 21
- Spring Boot 3.4.0
- Spring Security (JWT)
- Spring Data JPA
- PostgreSQL / H2
- Gradle
- OpenAPI (Swagger)
